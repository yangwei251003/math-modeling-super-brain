# 数学建模任务工作流与技能扫描器

将题目、可用技能和阶段成果组织成工作计划，附零依赖的本地Skill目录分类脚本。

![工作流示意，非运行截图](docs/workflow.svg)

## 实际范围

脚本能够读取指定目录并按关键词分类，不能验证被扫描Skill的学术正确性、实际可用性或授权；完整研究仍依赖宿主和真实数据。

## 安装与调用

1. 准备支持 `SKILL.md` 的AI Agent宿主。
2. 将完整目录以 `math-modeling-super-brain` 放入该宿主的用户技能目录；Codex示例为当前用户下的 `.codex/skills/`，其他宿主按其说明配置。
3. 保留正文与子目录相对结构，重新加载技能清单；调用方式取决于宿主。

示例：

> 用 $math-modeling-super-brain 只读指定技能目录与题目，说明可用能力和缺口，给出有验证节点的研究计划。

## 技术与文件

Markdown工作流与参考模板由宿主按需读取；提到的外部Skill属于各自维护者，未随本仓库重新分发。真实比赛材料、客户资料、账号配置、私人状态和依赖缓存不在仓库内。

Python 3.10+、标准库即可运行辅助扫描器：

```sh
python scripts/scan_skills.py --paths examples/skills --format json
```

这只读取仓库内原创示例。实际安装目录通过 `--paths` 指定；输出可能包含本地路径，应留在本地。
