# 数学建模标准论文结构模板

当用户未提供自定义模板时，使用以下标准结构作为论文生成骨架。

## 中文论文模板（国赛/CUMCM 风格）

### 第 1 页：摘要

```
论文题目（可选）

摘要

（一段式或分段式，不超过 1 页）

本文针对[问题背景]，建立了[核心模型名称]模型来解决[具体问题]。
首先，[方法一简述]。其次，[方法二简述]。然后，[方法三简述]。
结果表明，[关键数值结果]。经过[灵敏度分析/误差分析]验证，模型具有良好的[稳定性/准确性]。
本文的创新点在于[创新点]。最后，对模型进行了评价，并提出了改进方向。

关键词：[关键词1]; [关键词2]; [关键词3]; [关键词4]; [关键词5]
```

### 问题重述

```
1. 问题重述

1.1 问题背景
（用自己的话重述问题背景，不要直接复制原题）

1.2 问题提出
（明确列出需要解决的具体子问题）
  (1) ...
  (2) ...
  (3) ...
```

### 问题分析

```
2. 问题分析

（分析每个子问题的本质、难点、可能的方法方向）
（注意：这部分展示建模思路，体现逻辑性）

2.1 问题一分析
2.2 问题二分析
2.3 问题三分析

（包含）总体思路流程图
```

### 模型假设与符号说明

```
3. 模型假设与符号说明

3.1 基本假设
  (1) 假设1：...
      (理由：...)
  (2) 假设2：...
      (理由：...)

3.2 符号说明
| 符号 | 含义 | 单位 |
|------|------|------|
| x    | ...  | ...  |
| y    | ...  | ...  |
```

### 模型建立与求解

```
4. 模型建立与求解

4.1 模型一：[模型名称]
  4.1.1 建模思路
  4.1.2 模型建立
    （详细推导过程，公式使用 LaTeX）
  4.1.3 模型求解
    （求解算法、步骤、关键代码逻辑）
  4.1.4 结果分析
    （展示结果图表，分析数据含义）

4.2 模型二：[模型名称]
  ...

4.3 模型三：[模型名称]
  ...
```

### 模型检验

```
5. 模型检验与分析

5.1 误差分析
  （计算误差指标，分析误差来源）

5.2 灵敏度分析
  （改变关键参数，观察结果变化）
  （附灵敏分析的图表）

5.3 稳定性检验
  （如适用）
```

### 模型评价与改进

```
6. 模型评价与改进

6.1 模型优点
  (1) ...
  (2) ...

6.2 模型缺点
  (1) ...
  (2) ...

6.3 改进方向
  (1) ...
  (2) ...
```

### 参考文献

```
7. 参考文献

[1] 作者. 文献标题[J]. 期刊名, 年, 卷(期): 页码.
[2] ...
```

### 附录

```
附录

附录A：关键代码
附录B：详细数据表格
附录C：补充推导过程
```

## 英文论文模板（美赛/MCM 风格）

### Summary Sheet (Page 1)

```latex
% COMAP Official Summary Sheet

Summary

\noindent
This paper develops [models] to address [problem]...

We first... Then... Finally...

The results show that [key findings]. Sensitivity analysis confirms [stability]...

Keywords: keyword1, keyword2, keyword3, keyword4
```

### Main Body

```
1. Introduction
  1.1 Background
  1.2 Problem Statement
  1.3 Our Approach

2. Assumptions and Justifications

3. Model Development
  3.1 Model I: [Name]
    3.1.1 Model Formulation
    3.1.2 Solution Approach
    3.1.3 Results and Analysis
  3.2 Model II: [Name]
    ...

4. Model Analysis and Validation
  4.1 Error Analysis
  4.2 Sensitivity Analysis
  4.3 Robustness Check

5. Strengths and Weaknesses
  5.1 Strengths
  5.2 Weaknesses

6. Conclusions

7. References

8. Appendix
```

## 写作要点清单

1. **摘要先行**：摘要写得不好，评审可能直接淘汰
2. **逻辑清晰**：问题重述 → 问题分析 → 建模 → 求解 → 分析 → 评价，一环扣一环
3. **图表精美**：用 Python（matplotlib/seaborn）或 MATLAB 生成高清图表
4. **公式规范**：所有数学公式用 LaTeX 格式书写 (`$...$` 或 `$$...$$`)
5. **实事求是**：不要说「完美解决了问题」，要用数据说话
6. **引用规范**：所有引用都要标注，格式统一
7. **附录完整**：代码要加注释，数据要整理清晰
